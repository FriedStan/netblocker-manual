# Netblocker manual

คู่มือของ Netblocker รุ่น 1.8.0 ระบบควบคุมการเข้าถึงอินเทอร์เน็ตในห้องปฏิบัติการผ่านไฟร์วอลล์ FortiGate

- [คู่มือการใช้งานสำหรับผู้ใช้](user-manual.md) สำหรับอาจารย์และเจ้าหน้าที่: การจองห้อง การสร้าง แก้ไข และทดสอบนโยบาย แม่แบบ และการมอบหมายสิทธิ์
- [คู่มือสำหรับผู้ดูแลระบบและการติดตั้ง](admin-manual.md) สำหรับผู้ดูแลระบบและฝ่ายสารสนเทศ: งานในหน้าผู้ดูแล ค่าตั้งค่า ฐานข้อมูล การนำส่งระบบ และเครื่องทดสอบ

ภาพหน้าจอทั้งหมดจับจากระบบที่ใช้งานจริง หน้าจอของระบบเป็นภาษาอังกฤษ
